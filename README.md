# 📺 TV Player — Неофициальный клиент VK Live

Лёгкий, быстрый и **защищённый** клиент для просмотра стримов VK Live на Android TV и мобильных устройствах. 

## ✨ Ключевые возможности

*   **🛡 DNS-over-HTTPS (AdGuard):** Все сетевые запросы приложения (включая Python-скрипты) проходят через зашифрованный DNS AdGuard с возможностью мгновенного переключения на системный DNS прямо из настроек.
*   **🐍 Автономный резолвинг:** Использование `yt-dlp` (Python) прямо на устройстве. Никаких сторонних серверов, всё работает локально и напрямую с CDN VK.
*   **🎮 Полный контроль пультом:** Удобная навигация, быстрое переключение каналов (вверх/вниз), меню выбора канала по кнопке ОК.
*   **📊 Диагностика в реальном времени:** Встроенная проверка работоспособности DoH, отображение разрешения, битрейта и размера буфера во время просмотра.
*   **⭐ Умный кэш и Избранное:** Импорт/экспорт списка любимых каналов, автоматическая очистка мусора и защита от зависаний плеера.

## ⚠️ Дисклеймер

Это приложение является **неофициальным** клиентом. Автор проекта **никак не связан** с компанией ВКонтакте (VK) или разработчиками AdGuard.
Приложение не использует официальное API VK с ключами разработчика. Оно использует открытые веб-эндпоинты и публичный DNS исключительно для обеспечения личного просмотра контента. Вы используете приложение на свой страх и риск.
